# Decisions

One entry per decision. Status is `Decided`, `Proposed`, or `Open`.

- **Decided** — settled. Code may rely on it.
- **Proposed** — waiting for the owner's confirmation. Not settled: flag it if a later task depends on it.
- **Open** — nothing chosen. Work around it, do not assume.

A change to a `Decided` entry needs a new entry that supersedes it, with a reason. Never edit history silently.
